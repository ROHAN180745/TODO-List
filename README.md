# 📝 To-Do List

A simple and beginner-friendly **To-Do List Web App** built using HTML, CSS, and JavaScript. It allows users to add tasks and delete them when they are no longer needed.

## 🚀 Features

* ➕ Add new tasks
* ❌ Delete tasks
* 🎨 Simple and attractive user interface
* 🌈 Gradient background
* 📱 Responsive layout

## 🛠️ Technologies Used

* **HTML5** — For the structure of the application
* **CSS3** — For styling and layout
* **JavaScript** — For adding and deleting tasks
* **Font Awesome** — For the delete icon

## 📂 Project Structure

```text
todo-list/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter a task in the input field and click the **Add** button.

5. Click the ❌ icon to delete a task.
